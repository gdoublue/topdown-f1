## 一、它的物理引擎是怎么搭的

### 1. 地形 = 解析高度场（起伏的根基）
```
analytic(x, z, amp)            // 坡道 + 凹坑 + 4 个 mogul 包 + 斜坡，全部解析函数叠加
heights[193×193]               // 150m 场地，STEP≈0.79m
hAt(x, z)                      // 双线性采样（与渲染网格完全一致）
nAt(x, z)                      // 有限差分求法线（±0.9m 采样）
```
关键设计：**地形是"函数"，不是碰撞体**。物理和渲染从同一个 `hAt` 采样，永远一致。
渲染网格是 193×193 的 PlaneGeometry 顶点直接 setY(heights)，再按高度/坡度/距水坑距离
混顶点色（草地→泥土→岩石）。

### 2. 固定物理步长 + 累加器
```
FIXED = 1/180s，每帧 while (acc >= FIXED && sub < 8) physics(FIXED)
```
悬挂弹簧刚度大（K≈9e4），变步长会发散，固定步长是硬前提。

### 3. 刚体六自由度
- `CAR = { mass: 1400, Ix: 2150, Iy: 2520, Iz: 560, pos, quat, vel, omega }`
- 力/力矩累加后：`vel += F·dt/m`；**力矩先转到车体坐标系除以 I 再转回世界系**
- 四元数积分：`q += 0.5·dt·(ω⊗q)`，再 normalize
- 数值异常（isFinite 检查）自动复位

### 4. 四轮独立悬挂 = "从上支点向车体下方打射线"
- 每轮一个**悬挂上支点** HP（车身坐标 ±0.86 横向、±1.42 纵向、y=0.06）
- 每步把 HP 变换到世界系，沿 **车体 -up 方向**（不是世界 -y！车侧倾时射线跟着歪）打射线：
  `rayTerrain()`: 10 步步进粗查 + 13 次二分求精，对 hAt 高度场求交
- 悬挂行程 `susLen ∈ [REST−0.14, REST+0.14]`，弹簧力：
  `N = K·comp − C·relN`（comp = 自由长 − 当前长，relN = 支点速度·法线），
  加**渐进限位缓冲** `1.2e7·bs²`（压到底附近刚度指数上升），钳位 [0, 45000]
- 力沿**接触点法线**施加在接触点 → 产生真实的俯仰/侧倾力矩

### 5. 轮胎 = 摩擦圆（friction circle）
```
纵向 Fl = 驱动(8200×0.25×throttle×速度衰减) − 制动 − 滚动阻力(0.022·N·sgn(vf))
横向 Fs = −vl·LAT_K（vl = 接触点侧向速度）
maxF = μ·N（μ=1.08 干地 / 0.62 涉水）
|（Fl,Fs）| > maxF → 整体缩放到圆上，slip = 1 − s   ← 漂移/锁死的来源
```
前轮的 `_fw` 先绕**车体 up 轴转 steer 角**再投影到接触平面 → 转向只改变前轮纵向力方向。

### 6. 防倾杆 ARB —— "转弯外侧更高"的车辆侧来源
```
arb = (susLen左 − susLen右)·ARB_K，钳 ±6000
左右轮沿车体 up 反向各施加 ±arb
```
弯中外侧悬挂被压缩、内侧被拉伸 → ARB 产生反向力矩 → **车身向外侧倾**
（车身外侧低、但**轮胎载荷向外侧转移**）。这是"过弯侧倾"的物理来源。

### 7. 其他值得抄的细节
| 细节 | 做法 |
|---|---|
| 车底防插地 | 6 个车底触地点，穿透量惩罚弹簧 `pen·260000 − vn·5200` |
| 横摆阻尼 | 直接对 up 轴角速度加 `-ω·900` 力矩（防甩尾抖动） |
| 空气阻力 | `F = −v·1.55·|v|`（二次项） |
| **转向锁止角随速度衰减** | `maxSteer = 0.56 − 0.30·clamp(|v|/24)`，且转向有速率限幅（打 4.2/s 回 7.5/s） |
| 相机防穿地 | `camY = max(camY, hAt(x,z) + 0.9)` |
| **天穹跟随相机** | `sky.position.copy(camera.position)` —— 与本修复 same 做法 ✓ |
| 昼夜系统 | 太阳高度角驱动 3 套调色板插值（day/dusk/night），雾密度联动 |

## 二、映射到 topdown-f1：怎么引入起伏 / 立交 / 弯道外高

> **实施状态（2026-10-29）：P1 + P2 已落地。**
> - 数据层：`tracks.js` 每赛道 `hills/bankK/bankMax`；`geometry.js` 新增 `h[]/bank[]/grade[]`
>   （整数谐波剖面建在弧长 cumDist 上，环形闭合，发车区 ±350m 渐入；bank=-K·curvS 外高内低）
>   与采样入口 `roadAt(s)` / `roadElev(i, off)`。
> - 渲染层：`ribbonGeometry/quadSegmentsGeometry` 顶点统一 `+roadElev(i,off)`（沥青/边线/路牙/
>   起终点线/广告牌全跟随）；新增 `buildSkirts()` 路基裙边（路缘外沿→草地斜坡，高度下限 0.6m 不穿地）。
> - 车辆：physics 每帧 `updateRoadProfile(car)` 写入 `car.roadY/roadPitch/roadRoll`
>   （出路面 6m 渐变到草地 0）；`car/shared.js` 的 `syncCarPose` 用 YXZ 欧拉叠 pitch/roll；
>   刹车印带 `s.y` 贴合路面；camera3d 相机/注视点 clamp 到路面上方。
> - P2：`stepLongitudinal` 坡度重力 `speed -= 9.81·roadPitch·dt`。
> - 回归：ai-sim 全赛道正常（上赛最快 76.05s、云栖 43.35s 与基线一致、斯帕 +0.3% 即坡度重力本身）。
> - 未做：P3 立交（现有赛道均不自交，需要专门设计一条交叉布局赛道）、P4 四轮仿真模式。

我们的现状：物理是 2D 平面（physics.js，y 恒 0），权威数据是
`track/geometry.js` 的 `pts/nor/hw/curvS`（弯道曲率已有！），
3D 网格（track3d.js）、刹车印（effects3d.js）、相机（camera3d.js）全部从这条数据流取值。

### 数据层（一切的起点）：给 geometry.js 增加两个通道
```
h[i]      // 每个赛道采样点的高度（米）：直线缓坡 + 弯道起伏，用平滑噪声/正弦包络生成
bank[i]   // 横坡角（弧度）：曲率大的路段 → 弯道外高内低（外轨超高 superelevation）
          // bank[i] = clamp(curvS[i] × K_bank, -0.12, 0.12)，直线为 0，进弯渐入出弯渐出（天然由曲率连续性保证）
```
交叉赛道（立交）：赛道自交处，给其中一条在交叉区间一个 **+6~8m 的高度包**
（smoothstep 包络），另一条保持 0 → 天然形成桥梁穿越，物理上互不干扰。

### 采样函数（物理与渲染共用，学参考项目的"地形是函数"）
```
trackH(x, z) → { h, pitch, roll }   // 最近赛道点的 h[i] 纵向插值 + bank[i] 横向插值
```
放置在 track/geometry.js（权威数据层），physics / render3d / effects3d / camera3d 全部消费它。

### P1 视觉层（物理保持平面，风险最低）
- track3d：沥青/路肩/边线/路牙顶点按 `h + bank×横向偏移` 抬升；桥墩装饰
- 车模：`root.position.y = trackH(car)`，pitch/roll 用坡度驱动（视觉四元数叠加）
- effects3d：刹车印 y 从 0.058 改为 `trackH + 0.008`
- camera3d：加 `camY = max(camY, trackH+0.9)`（参考项目同款防穿地）

### P2 物理层（高度进入 s/d 街机物理）
- 纵向：重力分量 `g·sin(pitch)` 并入加速度曲线（上坡减速/下坡加速）
- 横向：banking 等效提升 latGrip：`latGrip_eff = latGrip·(1 + k·bank·sgn)`——
  弯道外高 → 重力横向分量压向弯内 → 更高过弯极限（真实 superspeedway 原理）
- 腾空：短坡顶允许 `car.air` 状态（参考项目的 groundedN==0 处理可以借）

### P3 车辆机动性升级（可选，学参考项目）
- 把 `maxOmega` 恒定改为**转向锁止角随速度衰减**（0.56−0.30·v/24 的思路），
  我们高速时的转向已经受 latGrip 限制，这一条主要改"低速太灵"的手感
- 完整四轮悬挂仿真（射线+弹簧+摩擦圆+ARB）是"仿真模式"级别的重构，
  圈速/AI/联运会全部重调，建议作为独立分支验证后再合

### P4 交叉立交
- geometry.js 检测自交段 → 高度包 → 物理自动分离（trackH 采样天然支持）
- 3D：桥面段 + 桥墩 + 护栏；minimap 无需改动
